# Project 2 - Tags and Locks

## Goal
In this project, i created tags and locks on resources in a resource group. This is to show what can be done, how to prevent accidental deletion and also modification of resources.

## Azure services used
- Resource tags
- Resource locks
- Azure portal

## Steps completed
1. I created resource in a resource group, a storage account. I added tags to the resources by department or environment. Filtered by tags. I also applied delete locks and read-only locks.  I
tested it out and also tried to make changes and delete the resource and show the error message when you try a blocked action..
2. I removed all the tags and locks from the resources and then deleted the resource group. which deletes all the resources within the group too.

## What I learned
I learned how tags and locks prevent deletion and also modification in resources. I also learnt how to apply my learning into practice. locks and tags.
