# Project Static Website

## Goal
In this project, I created a resource group, set up a storage account and turned on the static website hosting feature.

## Azure services used
- Resource groups
- Storage accounts
- Static website hosting
- $web container

## Steps completed
1. I first created a resource group, after that i created a blob storage account. After that i made sure to enable static website hosting. Doing this created a special container named $web where i uploaded my static website page.

2. After all of these steps were done, i made sure to see if i can update the static website by overwriting the index.html file that i had already uploaded with an updated index.html. After all had been done, i made sure to delete the resource group.
deleting the resource deletes all the resources within the resource group. That's to make sure i dont get charged for using the azure services.

## What I learned
I learned how to create a resource group, a storage account within a resource group. How to enable static website hosting. By the end of it i now i have a public URL ready to serve web content even though I havent uploaded any files yet.
